## Запуск
1. Скачайте содержимое репозитория, сохранив папку data рядом с блокнотом.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Откройте блокнот в Jupyter Notebook или JupyterLab; при необходимости установите интерфейс командой `pip install jupyterlab`.
4. Выполните все ячейки сверху вниз в чистом ядре из папки проекта.

По умолчанию `COLLECT_DATA=False`: сбор с сайта отключён, данные читаются только из CSV.
Для новой выгрузки установите `COLLECT_DATA=True` и выполните отдельную ячейку сбора,
затем ячейку чтения CSV. Это действие требует доступа к сайту и заменяет сохранённый CSV.

## Метод и результат
Target равен 1, если доля побед команды в следующем году строго выше медианы этого года.
Медиана рассчитана по полной исходной таблице будущего года.
Train: target_year <= 2005; validation: 2006–2008; test: 2009–2011.

Финальная модель: SimpleImputer(strategy="median"), StandardScaler,
LogisticRegression(max_iter=1000). Признаки: win_rate, goal_diff, goals_against,
win_rate_squared. Порог классификации: 0.5.

Test: ROC-AUC = 0.7548, F1 = 0.7059, accuracy = 0.6629.
Матрица ошибок: TN = 23, FP = 24, FN = 6, TP = 36.
При доработке модель, признаки и временное разбиение не менялись;
повторный расчёт подтвердил исходные метрики.
